# phrits.com

The Wix Headless Astro site is in [`wix-headless/`](wix-headless/). Open that folder in VS Code, and use the `wix-headless` branch for edits and commits.

The app contains the migrated archive, recipes, Notes/blog, and a legacy URL redirect handler. Redirect destinations are maintained in `wix-headless/src/data/legacy-redirects.json`.

A small amount of old, unimported material remains at the repository root for reference; it is not part of the Wix app. The old site source and migrated content are recoverable from Git history.
